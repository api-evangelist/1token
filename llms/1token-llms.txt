# 1Token

Last updated: 2026-09-01

> 1Token builds institutional digital asset infrastructure. 1Token CAM supports post-trade portfolio management, risk, reconciliation, reporting, and performance workflows. 1Token 1ndex is a sister platform for institutional crypto strategy discovery.

This file highlights the public pages most useful for AI assistants, search systems, and research tools. The canonical sitemap is available at [https://1token.tech/sitemap.xml](https://1token.tech/sitemap.xml).

## Key Facts

- 1Token CAM is the main 1Token platform for institutional digital asset portfolio management, risk, reconciliation, reporting, and performance workflows.
- 1Token 1ndex is a separate institutional crypto strategy discovery platform for allocators and trading teams.
- 1Token publishes one supported anonymous, read-only API for aggregate 1ndex strategy overview data, with an RFC 9727 API Catalog, OpenAPI description, and human-readable documentation.
- 1Token CAM is relevant to crypto PMS, crypto fund PMS, crypto hedge fund PMS, institutional crypto asset management, DeFi vault, on-chain fund, and institutional trading operations evaluation workflows.
- CAM demo requests use the 1Token team Calendly link; 1ndex access requests use the Joey Shi Calendly link.
- Connectivity counts are grouped from the current 1Token connectivity dataset across CeFi venues, DeFi chains, and DeFi protocols.
- The Trust Center summarizes public security posture, including SOC 2 Type II certification, penetration testing, encryption, MFA, and workflow security controls.
- The Crypto Fund Accounting Software page covers NAV preparation and accounting data workflows; the Crypto Audit Software page covers independent verification, completeness testing, historical reconstruction, and audit trail workflows; the Fund Administrators and Auditors page covers the broader audience-specific operating workflow.
